FileWheel - version portable / portable version
================================================

FR
- Lancez FileWheel.exe : aucune installation, aucun droit administrateur.
- Vos réglages, l'historique et les moteurs téléchargés sont rangés dans le
  sous-dossier « FileWheel-data » (créé au premier lancement), à côté de FileWheel.exe.
- Mise à jour : téléchargez la nouvelle archive portable et remplacez les fichiers,
  en gardant le dossier « FileWheel-data ».
- Désinstallation : double-cliquez sur UNINSTALL-PORTABLE.bat (arrête FileWheel, retire
  le démarrage automatique s'il a été activé, puis supprime ce dossier).
- Le fichier « FileWheel.portable » active le mode portable : ne le supprimez pas.

EN
- Run FileWheel.exe: no installation, no administrator rights.
- Your settings, history and downloaded engines are stored in the "FileWheel-data"
  subfolder (created on first launch), next to FileWheel.exe.
- Update: download the new portable archive and replace the files, keeping the
  "FileWheel-data" folder.
- Uninstall: double-click UNINSTALL-PORTABLE.bat (stops FileWheel, removes auto-start if
  it was enabled, then deletes this folder).
- The "FileWheel.portable" file turns portable mode on: do not delete it.
